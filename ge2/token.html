theme

tokens · type

Every size token is in rem, so root font-size scales the whole page. Sample:

--text-xs --text-sm --text-md --text-xl --text-2xl --text-3xl

tokens · typography

Font, size, weight and colour for body text, h1–h6 and small. Each element reads its own tokens — --body-font, --h1-weight, --small-color… — declared in vars.css and applied in base.css. Every option is another token, written as var(--token); default drops the override and shows what the stylesheet gives. A default of inherit means the token is left at initial, so the element takes its parent's value. Heading sizes are the existing --h1…--h6. Changes persist, go into buckets, and are written to the :root block of download vars.css.

tokens · colour

These are the seed tokens. Everything under Derived is computed from them with color-mix() and updates live.
--gray drives the foreground ramp (--fg → --muted 50% → --subtle 85%, fading toward --gray), the same formula in both themes. The three borders mix --bg toward --fg (12% / 22% / 50%), also shared. --bg drives the surfaces: --bg-subtle 4% and --bg-muted 8% rise toward --tint, --bg-inset 40% sinks toward --sink — the theme only picks the direction (light: black / white, dark: white / black). --bg-overlay is the modal/drawer scrim only — black at 50%, translucent, the same in both themes. Each --seed-* drives one system colour — --seed-ac the accent (--ac, which anchors take), the other four --pr / --sc / --da / --wr.
Per row: the stylesheet's own value on the left — click it to copy into the override — then the picker, the value field, a live preview and a reset.
The text field is the real control: it takes any CSS colour (#1a2b3c, rebeccapurple, color-mix(…)) and the picker mirrors whatever it resolves to. Empty falls back to the stylesheet, and the placeholder shows that value.

Overrides sit inline on <html> and persist across reloads. Everything vars.css declares inside a [data-theme] block is kept per theme — the three hues and the five --seed-* — so switching swaps them in rather than clearing them. Only --white and --black are shared, because only they sit in the theme-neutral :root.

Derived

tokens · buckets

Every change is kept in localStorage, so a reload restores it. A bucket is a named snapshot of both themes — save, load, delete. download vars.css fetches the real sheet and appends your overrides, so the file is a drop-in replacement. Light and dark are both written, each scoped to its own [data-theme] block so neither leaks into the other.
