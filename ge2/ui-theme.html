ui theme · colour

Pick one colour, --co, and optionally the --bg and --fg it sits on (empty = the theme's). Under Derived, the scale steps --co toward --bg (bg1…bg5: 15, 30, 45, 60, 85%) and toward --fg (fg1…fg5), each labelled with what it is for. The demo beside it is painted from those steps only, through one set of roles per theme (see css/ge-maker.css). Every field takes any CSS colour. The label names the tokens in the CSS readout.
