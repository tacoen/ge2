--ac, its scale, and how it reads on real UI.

ui theme · accent

--ac, --bg and --fg start as the current theme's values from css/ge2/vars.css, and follow a theme switch. Edit one to preview an override on this panel only; overrides are kept per theme, and clearing a field goes back to the theme's value. Under Derived, the scale steps --ac toward --bg (bg1…bg5: 15, 30, 45, 60, 85%), toward --fg (fg1…fg5) and toward transparent (tr1…tr4), each labelled with what it is for — the same formulas as vars.css. The demo beside it — an app dashboard, a webpage and a docs article, one per tab — is painted from those steps through one set of roles per theme (see css/ge-maker.css); its status chips take the seeds. Swatch holds the component seeds — --seed-pr, -wr, -da, -sc, -in — whose --pr … tones are re-derived on the panel with the vars.css formulas. Every field takes any CSS colour.

Docs / Sharing / Share a folder

Share a folder

Give someone access to a folder with a link, or invite them by email so they can edit with you.

Create a link

Select the folder, press Ctrl + L, and copy the link. Anyone with the link can view; to let them edit, turn on edit rights. From the command line, use files share:

files share ~/Projects/ge2 --expires 7d
# https://files.example/s/4kq9 (view, expires in 7 days)
Note

Links to a folder include everything added to it later.

Link options

OptionDefaultWhat it does
--expiresneverTurns the link off after a time, e.g. 7d
--editoffLets people with the link change files
--passwordnoneAsks for a password before opening
Before you share

Edit rights let people delete files. Deleted files stay in Trash for 30 days.

Sharing a folder never moves it. It stays in your Files, and you can revoke access at any time.
