icons · add / edit

Author the set from the page. Every tile has an edit button; the last tile adds a new icon. Paste either a whole <svg> or just its contents — the wrapper is stripped, since icons-list.js stores the body only and icx.svg() supplies the rest. Changes live in localStorage and apply to this page immediately; export writes a complete icons-list.js for you to drop into js/ge2/.
