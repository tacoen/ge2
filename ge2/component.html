button · styles × tones × states

Each row is a colour token, each column a state. Classes live in css/ge2/utils.css: .btn (or a bare button) plus a style — .rounded .plain .outline .naked .link — and a tone — .pr .sc .da .wr .in .ac. The :hover / :focus columns are forced with .is-hover / .is-focus; the live column is a real button — hover it, Tab to it.

button · sizes

One spacing token per size — .vxs .xs .sm .md .lg .xlg — drives both padding and type; .sm is the default. .link keeps the surrounding text size until it is given one.
